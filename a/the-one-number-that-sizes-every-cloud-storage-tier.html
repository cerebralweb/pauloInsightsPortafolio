THE ONE NUMBER THAT SIZES EVERY CLOUD STORAGE TIER

In this article ❧ Storage planning in the cloud depends on knowing how volume splits across access tiers before a single file moves. When each tier is defined as a multiple of another, the whole collapses into a set of equal units, and finding one unit fixes all the rest. This problem shows how ratio relationships turn a large total into a single base quantity, and how Python can size every tier from that one value.

The Problem

A cloud operations lead has 1,400 stored datasets to reorganize across three access tiers, hot, warm, and cold. The warm tier holds 4 times as many datasets as the cold tier, and the hot tier holds half as many datasets as the warm tier.

How many datasets are in the cold tier?

  • a) 200
  • b) 224
  • c) c
  • d) 700
Click to Reveal the Answer

Correct Answer: a) 200 ✅

Math Solution

Set the cold tier as one unit. The warm tier is 4 units and the hot tier is 2 units, so the total is 7 units. Dividing 1,400 by 7 gives the size of one unit.

Every tier is a multiple of the cold tier, so the whole total is exactly 7 cold tiers.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. Cold tier: 1 unit
  2. Warm tier: 4 units
  3. Hot tier: 2 units
  4. Total units: 1 + 4 + 2 = 7
  5. One unit: 1,400 ÷ 7 = 200
  6. Cold tier size: 200 datasets

Formal Proof

Let c be the number of datasets in the cold tier, a positive integer. The warm tier holds 4c and the hot tier holds 2c. The three tiers sum to 1,400, so the governing equation is c + 4c + 2c = 1,400.

  1. Distributive law. c + 4c + 2c = 7c. The three like terms factor into 7c through c(1 + 4 + 2).
  2. Substitution. The equation becomes 7c = 1,400, replacing c + 4c + 2c with 7c.
  3. Multiplication property of equality. Multiply each side by one over 7, giving (1/7)(7c) = (1/7)(1,400).
  4. Multiplicative inverse and identity. The left side reduces to c, since one over 7 times 7 is 1 and 1 times c is c.
  5. Cancellation law. The right side is 1,400 over 7, which equals 200.
  6. Transitivity of equality. Therefore c = 200.

Check. Cold 200, warm 800, hot 400. The sum is 1,400, so the total matches.

Historical Background

Splitting a whole into parts fixed by ratio is one of the oldest practical uses of arithmetic. Merchants in medieval trade cities divided profits among partners according to the shares each contributed, reducing a lump sum to a count of equal parts before paying anyone. The same logic drives modern capacity planning, where a total is carved into proportional slices long before physical resources are assigned.

Python Version

This function sizes any tier from a total and the two multiples that define the structure, so it works for storage, budgets, or headcount.

def tier_sizes(total, warm_per_cold, hot_per_warm):
    units = 1 + warm_per_cold + hot_per_warm * warm_per_cold
    cold = total / units
    warm = warm_per_cold * cold
    hot = hot_per_warm * warm
    return {"cold": cold, "warm": warm, "hot": hot}


print(tier_sizes(1400, 4, 0.5))

Run it with the total and the two ratios, and it returns 200 for the cold tier, 800 for warm, and 400 for hot.
