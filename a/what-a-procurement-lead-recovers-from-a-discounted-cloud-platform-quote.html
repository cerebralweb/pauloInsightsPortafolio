WHAT A PROCUREMENT LEAD RECOVERS FROM A DISCOUNTED CLOUD PLATFORM QUOTE

In this article ❧ A vendor quote almost never arrives as a single figure. It arrives as a discounted base plus a fixed fee, and the buyer who wants to know the value of the concession has to work backward to the price the vendor started from. This problem shows how one linear equation recovers a hidden list price from a negotiated quote, and how a short Python function turns that recovery into a tool a procurement team can reuse on every renewal.

The Problem

A procurement lead at a mid market retailer negotiated the annual price of a cloud cost management platform. The negotiated price came to half the list price plus 65,000 pesos.

The negotiated price was 325,000 pesos. What was the list price?

  • a) 1,300,000
  • b) 650,000
  • c) 260,000
  • d) 520,000
Click to Reveal the Answer

Correct Answer: d) 520,000 ✅

Math Solution

The quote has two parts, so the fixed fee comes off first. Subtract 65,000 from 325,000 to isolate half the list price, then double the remainder to recover the whole.

The fee is a constant and the discount is a factor, so they have to be undone in reverse order of how they were applied.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. Governing equation: p/2 + 65,000 = 325,000, where p is the list price
  2. Fixed fee removed: 325,000 − 65,000 = 260,000
  3. Half the list price: p/2 = 260,000
  4. Discount undone: 2(260,000) = 520,000
  5. List price: p = 520,000
  6. Check: 520,000/2 + 65,000 = 325,000

Every Step, and the Property That Licenses It

The breakdown above states what happens. The sequence below states why each move is allowed. Every step names one property, gives it in general form, then applies it to the figures in the quote.

Notation

  • p is the list price in pesos, the unknown, a positive rational.
  • p/2 is half the list price.
  • 65,000 is the fixed fee added to the halved price.
  • 325,000 is the negotiated price, the value the equation is set equal to.
  • 260,000 is the value of p/2 once Step 4 fixes it.
  • 520,000 is the value of p once Step 8 fixes it.
  • ⇒ reads implies, and ≠ reads is not equal to.

Setup. The negotiated price equals half the list price plus a fixed fee of 65,000. The negotiated price is fixed at 325,000. So p/2 + 65,000 = 325,000.

  1. Subtraction property of equality. x = y ⇒ x − c = y − c. Inference. p/2 + 65,000 − 65,000 = 325,000 − 65,000.
  2. Additive inverse and additive identity. x + (−x) = 0 and x + 0 = x. Inference. p/2 + 65,000 − 65,000 = p/2 + 0 = p/2. From line 1.
  3. Distributive law. cx − cy = c(x − y). Inference. 325,000 − 65,000 = 1,000(325) − 1,000(65) = 1,000(325 − 65) = 260,000.
  4. Transitivity of equality. x = y and y = z ⇒ x = z. Inference. p/2 = 260,000. From lines 1, 2 and 3.
  5. Multiplication property of equality. x = y ⇒ cx = cy. Inference. 2(p/2) = 2(260,000). From line 4.
  6. Cancellation law. For y ≠ 0, (yx)/y = x. Inference. 2(p/2) = (2p)/2 = p. From line 5.
  7. Distributive law, as in Step 3. c(x + y) = cx + cy. Inference. 2(260,000) = 2(200,000 + 60,000) = 400,000 + 120,000 = 520,000.
  8. Transitivity of equality, as in Step 4. Inference. p = 520,000. From lines 5, 6 and 7.

Verification. 520,000/2 + 65,000 = 260,000 + 65,000 = 325,000. Both sides match.

Answer. p = 520,000. The list price of the annual subscription was 520,000 pesos, which is option d.

Two Properties That Let a Buyer Undo a Fee

The additive inverse says every number has an opposite that cancels it. Add 65,000 and then subtract 65,000 and the net effect is zero. The additive identity says zero changes nothing, so what remains after the fee comes off is half the list price and nothing else. Step 1 used the inverse. Step 2 used the identity.

Historical Background

Removing a fee to see what lies underneath rests on two rules that commerce used long before algebra named them. Brahmagupta, writing in India in 628 CE, gave arithmetic rules for fortunes and debts in which a debt cancels an equal fortune and leaves nothing, and the compilers of the Nine Chapters on the Mathematical Art in Han China balanced grain and tax accounts by pairing off counting rods of opposite sign on a board.

Double entry bookkeeping, codified by Luca Pacioli in Venice in 1494, turned the same pair of rules into the test of a correct ledger, since every entry carries an offsetting entry and the book closes only when the difference reads zero and the balance still reads the same figure. A buyer stripping a fixed fee from a quote is doing what a Venetian merchant did with a debit and a credit, on a subscription instead of a cargo.

Python Version

The script recovers a list price from any quote built as a discounted base plus a fixed fee, so it works on renewals where the discount rate and the fee both change.

def list_price_from_quote(negotiated_price, fixed_fee, discount_factor=0.5):
    """Recover the list price behind a quote.

    The quote is assumed to be: negotiated_price = discount_factor * list_price + fixed_fee
    """
    if not 0 < discount_factor <= 1:
        raise ValueError("discount_factor must be greater than 0 and at most 1")

    base = negotiated_price - fixed_fee
    if base < 0:
        raise ValueError("fixed_fee cannot exceed the negotiated price")

    return base / discount_factor


if __name__ == "__main__":
    price = list_price_from_quote(325_000, 65_000)
    print(f"List price: {price:,.0f}")

Run it with python list_price.py and it returns 520,000 for the quote in this problem, along with the list price behind any other quote of the same shape.
