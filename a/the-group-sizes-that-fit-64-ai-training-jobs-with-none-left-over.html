THE GROUP SIZES THAT FIT 64 AI TRAINING JOBS WITH NONE LEFT OVER

In this article ❧ Cloud teams split work into groups so each server carries the same load. When a tool sets group sizes at random, the team needs the share of sizes that fit the work with nothing left over. This problem shows how counting outcomes gives that share, and how Python and a Claude skill turn the count into a tool the team can reuse.

The Problem

A company runs 64 AI training jobs in the cloud. A planning tool picks 2 digits at random from 0 to 9, inclusive, to form a group size. The same digit can be picked twice, and the first digit can be 0.

What is the probability that the group size splits the 64 jobs into equal groups with none left over?

  • a) 1 %
  • b) 4 %
  • c) 7 %
  • d) 8 %
Click to Reveal the Answer

The correct answer is c) 7 % ✅

Math Solution

The tool can form 10 × 10 = 100 group sizes. Seven of them are factors of 64, so the probability is 7 / 100 = 7 %.

Count all the sizes first, then count the sizes that fit, and divide the second count by the first.

Step by Step Breakdown

The following sequence shows how the probability is derived.

  1. Possible sizes. 10 choices × 10 choices → 100 sizes, from 00 to 99.
  2. Factors of 64. 64 = 2 × 2 × 2 × 2 × 2 × 2 → factors are 1, 2, 4, 8, 16, 32, 64.
  3. Sizes that match. 01, 02, 04, 08, 16, 32, 64 → 7 sizes. A first digit of 0 counts, e.g. 04 is 4.
  4. Probability. 7 / 100 → 0.07 → 7 %.
  5. Conclusion. The tool forms a size that splits the 64 jobs into equal groups in 7 % of its picks, which is option c.

How to Reason Through It

I ask how many digits the tool can pick. There are 10, from 0 to 9. I ask how many positions the group size has. There are 2. Each position has 10 options, so there are 10 × 10 = 100 group sizes. That is my denominator.

I ask how many of those sizes are factors of 64. There are 7. So 7 of the 100 sizes work, which is 7 in 100, or 7/100.

The factors of 64 that the tool can form are 01, 02, 04, 08, 16, 32 and 64.

The ratio 7/100 is the probability that the tool forms one of those 7 sizes. So the probability is 0.07, or 7 %.

Possible Traps

If you count 1, 2, 4 and 8 and forget that the tool forms 2 digit numbers, you choose b) 4 %. If you forget that the question asks for the factors of 64, and count 64 alone, you choose a) 1 %.

Historical Background

Gerolamo Cardano, a physician and gambler in Renaissance Italy, wrote the Book on Games of Chance around 1564. It was one of the first texts to measure chance as the outcomes that win against all the outcomes that can occur. In 1654, Blaise Pascal and Pierre de Fermat used the same idea in letters on how to split the stakes of a game that stopped before its end, a question of payment between players.

Python Version

This script counts every group size the tool can form and works out the share that fits the jobs, for any job count and digit range.

# This program works out the chance that a random group size splits the jobs into equal groups.
# It comes from a company that runs 64 AI training jobs, where a tool picks 2 digits to form a group size.
# The math idea is probability, which is the sizes that work divided by all the sizes the tool can form.
# You type in the number of jobs, the smallest digit, and the largest digit.
# It prints the chance, as a percent, that the group size leaves no job left over.

# This function does the math.
def chance_of_equal_groups(jobs, smallest_digit, largest_digit):
    # Start both counts at zero.
    all_sizes = 0
    good_sizes = 0
    # Try every first digit.
    for first_digit in range(smallest_digit, largest_digit + 1):
        # Try every second digit. The same digit can come up twice.
        for second_digit in range(smallest_digit, largest_digit + 1):
            # Join the 2 digits into one number. So 1 and 6 become 16.
            group_size = first_digit * 10 + second_digit
            # Count this size.
            all_sizes = all_sizes + 1
            # Count it as good if it splits the jobs with none left over. A size of 0 holds no jobs.
            if group_size > 0 and jobs % group_size == 0:
                good_sizes = good_sizes + 1
    # Divide the good sizes by all sizes and turn the result into a percent.
    return good_sizes * 100 / all_sizes

# Tell the reader what we will figure out.
print("What is the chance the group size splits the jobs into equal groups?")

# Ask for the number of jobs.
jobs = int(input("Number of AI training jobs? "))

# Ask for the smallest digit the tool can pick.
smallest_digit = int(input("Smallest digit the tool can pick? "))

# Ask for the largest digit the tool can pick.
largest_digit = int(input("Largest digit the tool can pick? "))

# Do the math.
result = chance_of_equal_groups(jobs, smallest_digit, largest_digit)

# Show a whole number when the percent has no decimals.
result = int(result) if result.is_integer() else round(result, 2)

# Print the answer with words that fit the scenario.
print("Chance the group size splits the", jobs, "jobs with none left over is", result, "%")

Paste it into Python in Windows Terminal, type 64, 0 and 9, and it returns 7 %.

# Equal Groups Chance Calculator

This skill finds the chance that a tool, picking 2 digits at random, forms a group size that splits a set of jobs into equal groups with none left over. It takes the number of jobs, the smallest digit, and the largest digit the tool can pick. It returns one sentence with the chance as a percent.

## Dependencies

No outside libraries or tools. Basic arithmetic is enough.

## Inputs

- **Number of jobs.** A whole number above 0, e.g. 64.
- **Smallest digit.** A whole number from 0 to 9, e.g. 0.
- **Largest digit.** A whole number from 0 to 9, equal to or above the smallest digit, e.g. 9.

## Steps

### Step 1. State the question

Tell the user the question to answer. What is the chance the group size splits the jobs into equal groups?

### Step 2. Collect the inputs

Ask for the number of AI training jobs, then the smallest digit the tool can pick, then the largest digit. Check that each value is a whole number.

### Step 3. List every group size

Pair each first digit, from the smallest to the largest, with each second digit in the same range. The same digit can appear twice. Join each pair into one number by taking the first digit times 10 and adding the second digit, e.g. 1 and 6 become 16, and 0 and 4 become 4. Count every size formed.

### Step 4. Count the sizes that work

If a size is above 0 and divides the number of jobs with no remainder, count it as a size that works. If not, skip it. A size of 0 holds no jobs, so it never counts.

### Step 5. Work out the chance

Multiply the count of sizes that work by 100, then divide by the count of all sizes. The result is the chance as a percent.

### Step 6. Report the result

If the percent is a whole number, show it with no decimals. If not, round it to 2 decimals. Return one sentence in the chat in this form. "Chance the group size splits the [number of jobs] jobs with none left over is [result] %". For 64 jobs and digits from 0 to 9, the result is 7 %. Save no file.

## Example Trigger Prompts

- "A tool picks 2 digits to make a group size. How often does it split my 64 jobs into equal groups?"
- "What is the chance a 2 digit number made from random digits is a factor of 64?"
- "How often do random team sizes fit my workload with nothing left over?"
- "Check the odds that a random group size divides my training jobs."
