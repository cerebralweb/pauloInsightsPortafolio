SPLIT THE MATERIAL, DIVIDE THE REST, COUNT THE PRODUCTION RUNS

In this article ❧ Manufacturing plans rarely hinge on a single figure. Before a run begins, a team traces how one shared material splits across products, and how the leftover portion sets a hard ceiling on output. This problem shows how a short chain of fraction operations models a real production decision, and how a small Python function turns that logic into a reusable tool.

The Problem

A factory received a supply of resin. It used 2/5 of the resin to mold casings and the rest to mold connectors. The casings consumed 16 kilograms of resin, and each connector run uses 2/3 of a kilogram.

How many connector runs did the factory complete?

  • a) 32
  • b) 24
  • c) 40
  • d) 36
Click to Reveal the Answer

Correct Answer: d) 36 ✅

Math Solution

First recover the total from the casing share. Since 2/5 of the total is 16 kilograms, the total is 40 kilograms. The connectors take the remaining 3/5, which is 24 kilograms. Then divide 24 by the run size of 2/3, the same as multiplying by 3/2, giving 36 runs.

Dividing by 2/3 is multiplying by 3/2, so every kilogram of resin covers one and a half connector runs.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. Total resin: 16 ÷ 2/5 = 40 kilograms
  2. Connector share: 40 × 3/5 = 24 kilograms
  3. Connector runs: 24 ÷ 2/3 = 24 × 3/2 = 36

Formal Proof

Let T be the total resin in kilograms, a positive rational. Let n be the number of connector runs, a positive integer. Let x be the resin in the 1/5 piece, so x = (1/5)T. Casings take 2/5 of T and equal 16 kilograms, so (2/5)T = 16. Connectors take 3/5 of T. Each run uses 2/3 kilogram, so (2/3)n equals the connector resin.

  1. Addition of fractions, read backward: 3/5 = 2/5 + 1/5. Read right to left, this splits 3/5 into the 2/5 piece and the 1/5 piece.
  2. Distributive law: the connector resin = (2/5)T + (1/5)T. Builds on line 1, multiplying the split by T.
  3. Substitution: the connector resin = 16 + x. Builds on line 2, replacing (2/5)T with 16 and (1/5)T with x.
  4. Multiplication fact: (2/5)T = 2x, since 2/5 = 2 × 1/5 and (1/5)T = x.
  5. Substitution: 16 = 2x. Builds on line 4, since (2/5)T = 16 and (2/5)T = 2x.
  6. Division property of equality: x = 8. Builds on line 5, dividing each side by 2.
  7. Substitution: the connector resin = 24. Builds on lines 3 and 6, replacing x with 8 in 16 + x.
  8. Substitution: the equation for runs is (2/3)n = 24. Builds on line 7.
  9. Multiplication property of equality: multiply each side by 3/2, giving (3/2)(2/3)n = (3/2)(24). Builds on line 8.
  10. Multiplicative inverse and identity: the left side is n, since (3/2)(2/3) = 1 and 1 × n = n. So n = (3/2)(24). Builds on line 9.
  11. Cancellation law: n = 36. Builds on line 10, writing (3/2)(24) as 3 × 2 × 12 over 2, the 2 cancels, leaving 3 × 12.

Check: casings take (2/5)(40) = 16, since T = 40 from x = 8 and T = 5x. Connectors take 16 + 8 = 24. And 36 runs × 2/3 = 24. All match.

Historical Background

Splitting a fixed quantity into shares, then counting how many equal portions the remainder yields, is one of the oldest tasks in applied arithmetic. Egyptian scribes divided grain and bread among workers with unit fractions, and the Rhind Mathematical Papyrus preserves these ration methods from around 1650 BCE. The same reasoning now sizes production runs, allocates budgets, and plans inventory across modern operations.

Python Version

The script recovers the total from a known share, then counts how many fixed portions the remainder yields, so it fits any split and any portion size.

from fractions import Fraction


def connector_runs(casing_fraction, casing_weight, run_size):
    """Count how many runs the leftover material allows.

    casing_fraction: share of the total spent on casings
    casing_weight: weight that share consumed
    run_size: material each run uses
    """
    total = Fraction(casing_weight) / Fraction(casing_fraction)
    connector_weight = total * (1 - Fraction(casing_fraction))
    return connector_weight / Fraction(run_size)


runs = connector_runs(Fraction(2, 5), 16, Fraction(2, 3))
print(runs)  # 36

Run it with the casing share, the casing weight, and the run size, and it returns the number of runs, here 36.
