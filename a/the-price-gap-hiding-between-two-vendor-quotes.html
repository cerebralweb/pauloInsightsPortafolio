THE PRICE GAP HIDING BETWEEN TWO VENDOR QUOTES The Price Gap Hiding Between Two Vendor Quotes the-price-gap-hiding-between-two-vendor-quotes

In this article ❧ Procurement teams rarely receive quotes in the same shape. One vendor prices a bundle of five, another a bundle of seven, and the totals alone say nothing about which is the better deal. The fix is to reduce each offer to a cost per unit, the one figure that lets quotes of different sizes stand side by side.

The Problem

A procurement team is comparing two software vendors for user licenses. Vendor Norte offers 5 licenses for 285 pesos. Vendor Sur offers 7 licenses for 420 pesos.

Which vendor is cheaper per license, and what is the difference?

  • a) Vendor Norte, 165 pesos
  • b) Vendor Norte, 3 pesos
  • c) Vendor Sur, 30 pesos
  • d) Vendor Norte, 165 pesos
Click to Reveal the Answer

Correct Answer: b) Vendor Norte, 3 pesos ✅

Math Solution

Divide each total by its pack size to get a cost per license, then subtract the smaller rate from the larger to find the gap. Norte lands at 57 pesos, Sur at 60 pesos.

Totals mislead when pack sizes differ. The cost per unit is the only fair basis for comparison.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. Norte per license: 285 ÷ 5 = 57 pesos
  2. Sur per license: 420 ÷ 7 = 60 pesos
  3. Cheaper vendor: 57 < 60, so Norte
  4. Price gap: 60 − 57 = 3 pesos per license

Proof With Named Properties

Let n be the Norte cost per license and s the Sur cost per license, both positive rationals. The quotes fix 5n = 285 and 7s = 420. Let d be the price gap per license.

  1. Cancellation law. For nonzero b, b·a ÷ b = a. So n = 57, since 285 ÷ 5 = (5·57) ÷ 5 and the 5 cancels.
  2. Cancellation law, as above. So s = 60, since 420 ÷ 7 = (7·60) ÷ 7 and the 7 cancels.
  3. Trichotomy. For two reals exactly one holds, less than, equal, or greater. From 57 < 60, Norte is cheaper per license.
  4. Additive inverse property. The difference is the first plus the negative of the second, and closure keeps it a number. So d = 3, since 60 + (−57) = 3.

Verification. 5·57 = 285 and 7·60 = 420, and 57 + 3 = 60, so the gap holds.

Historical Background

The cost per unit is one of the oldest tools of trade. Merchants in the medieval Mediterranean needed a single figure to weigh offers priced in different measures and different lots, and the practice spread through Europe with the commercial arithmetic of the Italian trading cities.

Leonardo of Pisa, known as Fibonacci, set out these methods for pricing and proportion in his Liber Abaci of 1202. The same reasoning now sits inside procurement, where a per license figure turns a pile of mismatched quotes into a ranked list.

Python Version

This function reduces any two vendor quotes to a cost per unit, names the cheaper vendor, and returns the price gap, so it works for licenses, subscriptions, or bulk orders.

def cheaper_vendor(qty_a, cost_a, qty_b, cost_b):
    rate_a = cost_a / qty_a
    rate_b = cost_b / qty_b
    if rate_a < rate_b:
        winner = "A"
    elif rate_b < rate_a:
        winner = "B"
    else:
        winner = "tie"
    gap = abs(rate_a - rate_b)
    return winner, gap

print(cheaper_vendor(5, 285, 7, 420))

Run it with the two quotes and it returns ('A', 3.0), meaning the first vendor wins by 3 pesos per license.
