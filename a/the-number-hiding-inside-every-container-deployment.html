THE NUMBER HIDING INSIDE EVERY CONTAINER DEPLOYMENT

In this article ❧ Capacity planning rests on fixed ratios between resource types. When several resource counts all scale off one base, a single known number can rebuild the entire deployment. This problem shows how one anchor value drives a chain of ratios, and how Python turns that logic into a reusable tool.

The Problem

Claudia managed a container deployment for her whole company. She launched twice as many web pods as API pods. Then she launched monitoring sidecars, one for every two API pods. Because the platform relied on persistent state, she attached three times as many storage volumes as monitoring sidecars. After the load test ended, there were 4 web pods, 5 API pods, and 1 monitoring sidecar sitting idle, and no storage volumes were left unattached.

How many of each stayed in active use during the test?

  • a) 32, 13, 8, 27
  • b) 36, 13, 8, 27
  • c) 31, 20, 8, 27
  • d) 30, 20, 9, 27
Click to Reveal the Answer

Correct Answer: a) 32, 13, 8, 27 ✅

Math Solution

The storage volumes are the one number you must know. Storage equals 1.5 times the API pods launched, so 27 divides back to 18 API pods. Every other count follows, then you subtract the idle leftovers.

Knowing 27 is the whole game, because with zero left over it fixes the base count that all the other ratios hang on.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. API pods launched: 27 times 2 divided by 3 equals 18
  2. Web pods launched: 2 times 18 equals 36
  3. Sidecars launched: 18 divided by 2 equals 9
  4. Web pods in use: 36 minus 4 idle equals 32
  5. API pods in use: 18 minus 5 idle equals 13
  6. Sidecars in use: 9 minus 1 idle equals 8
  7. Storage volumes in use: 27, none idle

Historical Background

Solving many linked quantities from one known value is the heart of a system of equations. Merchants and engineers used the method long before it had a name, splitting cargo, coin, and land by fixed proportions. In the 17th century René Descartes carried unknowns through equations as symbols, which made this kind of back-solving routine for anyone planning resources.

Python Version

The script takes the storage count and the idle leftovers, then rebuilds every active total, so it works for any deployment sized the same way.

# What this does: works out how many pods and sidecars stayed in active use during a load test.
# Where it came from: a container deployment with web pods, API pods, monitoring sidecars, and storage volumes tied together by fixed ratios.
# The math idea: one known number (the storage volumes) unlocks the base count, then the rest follow.
# You type in: the storage volumes in use, and the idle counts for web pods, API pods, and sidecars.
# It prints: how many web pods, API pods, sidecars, and storage volumes stayed in active use.

# This function does the math.
def active_use(storage_in_use, idle_web, idle_api, idle_sidecar):
    # The storage volumes are the one number you must know.
    # There are 3 storage volumes for every 1 sidecar, and 1 sidecar for every 2 API pods.
    # So storage equals 3 times half the API pods, which is 1.5 times the API pods.
    # Work backward from storage to get the API pods that were launched.
    api_launched = storage_in_use * 2 // 3

    # There were twice as many web pods launched as API pods.
    web_launched = 2 * api_launched

    # There was one sidecar launched for every two API pods.
    sidecar_launched = api_launched // 2

    # Active use is what was launched minus what sat idle at the end.
    web_used = web_launched - idle_web
    api_used = api_launched - idle_api
    sidecar_used = sidecar_launched - idle_sidecar

    # No storage volumes were left over, so all of them stayed in use.
    storage_used = storage_in_use

    return web_used, api_used, sidecar_used, storage_used

# Tell the reader what we will figure out.
print("Let's find how many pods and volumes stayed in active use.")

# Ask for the one number that unlocks the problem.
storage_in_use = int(input("Storage volumes in use: "))

# Ask for the idle leftovers.
idle_web = int(input("Idle web pods: "))
idle_api = int(input("Idle API pods: "))
idle_sidecar = int(input("Idle monitoring sidecars: "))

# Do the math.
web_used, api_used, sidecar_used, storage_used = active_use(storage_in_use, idle_web, idle_api, idle_sidecar)

# Print the answer with words that fit the scenario.
print("Web pods in use:", web_used)
print("API pods in use:", api_used)
print("Monitoring sidecars in use:", sidecar_used)
print("Storage volumes in use:", storage_used)

Run it, type 27, 4, 5, 1 at the prompts, and it returns 32, 13, 8, and 27.
