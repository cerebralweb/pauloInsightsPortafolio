THE ESTIMATE THAT LANDS WITHIN ONE KILOMETER OF EXACT

In this article ❧ Route planning rarely waits for a perfect figure. A dispatcher needs a fast sense of how far is left before the precise number is confirmed, so a rough estimate and an exact result serve two moments in the same decision. This problem shows how rounding each part first gives a quick check, while exact decimal subtraction gives the figure the system commits to.

The Problem

A freight carrier is tracking a long haul delivery. The full route to the customer warehouse is 245 km and 7/50. So far the truck has covered 128 km and 53/100.

How many kilometers remain? First give an estimate by rounding each segment to the nearest whole number, then give the exact figure.

  • a) 117 and 116.61
  • b) 116 and 116.61
  • c) 116 and 117
  • d) 117 and 117
Click to Reveal the Answer

Correct Answer: b) 116 and 116.61 ✅

Math Solution

Turn each mixed number into a decimal, then subtract. The route is 245.14 and the covered distance is 128.53. For the estimate, round each segment first, so 245.14 goes to 245 and 128.53 goes to 129, then subtract for 116. For the exact figure, subtract the decimals directly for 116.61.

Rounding sends 0.53 up to the next whole number, which is why the estimate of 116 sits just below the exact 116.61.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. Convert the route: 245 and 7/50 becomes 245.14 km
  2. Convert the covered distance: 128 and 53/100 becomes 128.53 km
  3. Round each segment: 245.14 to 245, and 128.53 to 129
  4. Estimate: 245 minus 129 equals 116 km
  5. Exact: 245.14 minus 128.53 equals 116.61 km

Proof With Named Properties

Compute mode. Let r be the exact remaining distance and e the rounded estimate, both in kilometers. The total route is 245 and 7/50. The covered distance is 128 and 53/100. Remaining distance is the total minus the covered distance, and the estimate rounds each segment to the nearest integer before subtracting.

  1. Equivalent fractions property. For nonzero k, a over b equals ka over kb. So 7/50 equals 14/100 equals 0.14, and the total is 245.14 km.
  2. Definition of a decimal fraction. A fraction with denominator 100 equals the decimal read in hundredths. So 53/100 equals 0.53, and the covered distance is 128.53 km.
  3. Rounding to the nearest integer. A value with fractional part below one half rounds down, otherwise up. 245.14 rounds to 245, since 0.14 is below one half. Builds on step 1.
  4. Rounding to the nearest integer, as in step 3. 128.53 rounds to 129, since 0.53 is at or above one half. Builds on step 2.
  5. Closure under subtraction. The difference of two reals is a real. The estimate equals 245 minus 129, which is 116. Builds on steps 3 and 4.
  6. Subtraction property of equality. Subtracting equal quantities from a common total preserves equality. The exact remainder equals 245.14 minus 128.53, which is 116.61. Builds on steps 1 and 2.

Verification. Add the covered distance back to the exact remainder. 116.61 plus 128.53 equals 245.14, which matches the total. The estimate 116 sits within one km of 116.61.

Historical Background

Mixed numbers and quick rounding grew out of the daily arithmetic of trade, where a merchant needed a workable figure faster than a precise one. Medieval European counting houses ran on fractions of standard units of weight and length, and clerks learned to round to the nearest whole before settling accounts to the last part. The spread of decimal measurement through the nineteenth century did not retire that habit, it split the work into two steps, a fast estimate to catch gross error and an exact figure to close the record.

Python Version

The script accepts each value as a whole part plus a fraction, then returns a rounded estimate and the exact remainder, so it fits any remaining amount problem, not just this route.

# What this does: works out how far is left on a trip, with a quick estimate first.
# Where it came from: a truck had a full route length and a distance already covered.
# The math idea: turn each mixed number into a decimal, then subtract.
# You type in: the whole part and the fraction for the full route and for the part done.
# It prints: a rounded estimate of the distance left and the exact distance left.

# This function turns a whole part and a fraction into one decimal number.
def to_decimal(whole, top, bottom):
    return whole + top / bottom

# This function rounds a number to the nearest whole number, half goes up.
def round_half_up(value):
    return int(value + 0.5)

# Tell the reader what we will figure out.
print("Let's find how far is left on the route.")

# Ask for the full route as a whole part and a fraction.
route_whole = float(input("Full route whole km: "))
route_top = float(input("Full route fraction top: "))
route_bottom = float(input("Full route fraction bottom: "))

# Ask for the distance covered as a whole part and a fraction.
done_whole = float(input("Covered whole km: "))
done_top = float(input("Covered fraction top: "))
done_bottom = float(input("Covered fraction bottom: "))

# Build the two decimals.
total = to_decimal(route_whole, route_top, route_bottom)
covered = to_decimal(done_whole, done_top, done_bottom)

# Estimate: round each part first, then subtract.
estimate = round_half_up(total) - round_half_up(covered)

# Exact: subtract the real decimals, then keep two places.
exact = round(total - covered, 2)

# Print both answers with words that fit the trip.
print("Estimated km left:", estimate)
print("Exact km left:", exact)

Run it in a terminal, type 245, 7, 50 for the route and 128, 53, 100 for the covered distance, and it returns an estimate of 116 and an exact figure of 116.61.

# Distance Remaining Estimator

This skill takes a full route length and a distance already covered, each written as a whole part plus a fraction, and finds how much distance is left. It first gives a fast estimate by rounding each value to the nearest whole number, then gives the exact figure to two decimal places. The same logic fits any remaining amount problem, e.g. budget left or work left.

---

## Dependencies

- None for the plain version. Standard arithmetic only.
- The `fractions` module from the Python standard library for an exact variant, when the fractions are messy and rounding error must stay out.

---

## Inputs

- **Full route**: a whole number of kilometers plus a fraction, given as three numbers, the whole part, the top of the fraction, and the bottom.
- **Distance covered**: the same three numbers for the part already done.

---

## Steps

### Step 1 — Gather the two values

Ask for the full route as a whole part, a fraction top, and a fraction bottom. Then ask for the distance covered in the same three parts. Show a short line first stating that the goal is the distance left.

### Step 2 — Turn each mixed number into one number

For each value, divide the fraction top by the fraction bottom and add the whole part. This gives one decimal for the full route and one for the distance covered.

### Step 3 — Build the estimate

Round each of the two decimals to the nearest whole number, sending a half up. Subtract the rounded covered distance from the rounded route. This is the estimate.

### Step 4 — Build the exact figure

Subtract the covered decimal from the route decimal without rounding first. Keep two decimal places on the result.

### Step 5 — Report both

Print the estimate and then the exact distance left, each with a short line that names the trip. Do not print only the numbers. Label them so the reader knows which is the estimate and which is exact.
