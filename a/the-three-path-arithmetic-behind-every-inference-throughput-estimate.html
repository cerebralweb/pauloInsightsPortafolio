THE THREE PATH ARITHMETIC BEHIND EVERY INFERENCE THROUGHPUT ESTIMATE

In this article ❧ Capacity planning for machine learning services rests on comparing rates that depend on one another. A fast path sets a reference, a slower path is expressed as a fraction of it, and a third path is defined by a gap from the second. This problem shows how a chain of a division and a subtraction turns one measured rate into a full picture of throughput, and how Python turns that logic into a reusable tool.

The Problem

An AI team runs three inference paths. The cached path handles 150 requests per hour. The cached path runs three times faster than the standard path. The fallback path handles 20 fewer requests per hour than the standard path.

How many requests per hour does the fallback path handle?

  • a) 20
  • b) 120
  • c) 40
  • d) 30
Click to Reveal the Answer

Correct Answer: d) 30 ✅

Math Solution

Find the standard path first. Divide the cached rate by 3 to get 50. Then subtract 20 to get the fallback rate.

The known rate is the cached path, but the target rate sits two operations away from it.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. Cached path rate: 150 requests per hour
  2. Standard path rate: 150 ÷ 3 = 50 requests per hour
  3. Fallback path rate: 50 − 20 = 30 requests per hour

Proof with Named Properties

Setup. Let s be the standard path rate in requests per hour, a positive rational. Let f be the fallback path rate. The cached path is 150 and equals three times the standard path, so 3s equals 150. The fallback path is 20 fewer than the standard path, so f equals s minus 20.

  1. Multiplication property of equality. If a equals b then c times a equals c times b. One third times 3s equals one third times 150, since the same factor multiplies each side of 3s equals 150.
  2. Multiplicative inverse and identity. A nonzero number times its inverse is one, and one times a equals a. So s equals 50. Builds on line 1, since one third times 3 is one and one third times 150 is 50.
  3. Substitution. Equals may replace equals. So f equals 50 minus 20. Builds on line 2, replacing s in f equals s minus 20 with 50.
  4. Arithmetic evaluation. No standard named property. The move rests on evaluating a difference. So f equals 30. Builds on line 3, since 50 minus 20 is 30.

Verification. The standard path is 50. Three times 50 is 150, which matches the cached path. The fallback path is 50 minus 20, which is 30.

Historical Background

Rates defined against one another are old. Merchants in medieval Islamic markets set prices and yields as fixed proportions of a reference measure, a practice carried into Europe through the rule of three in commercial arithmetic. The same move, take a known quantity, scale it by a ratio, then adjust by a fixed offset, still underlies how firms plan output when one measured figure anchors several dependent ones.

Python Version

The script turns the cached rate, the speed factor, and the offset into the fallback rate, so any set of three inputs returns an answer.

def fallback_path_rate(cached_rate, speed_factor, offset):
    standard_rate = cached_rate / speed_factor
    return standard_rate - offset

print(fallback_path_rate(150, 3, 20))  # 30.0

Run it with any three values and it returns the fallback rate; with 150, 3, and 20 it returns 30.
