SIXTY MINUTES UNTIL TWO SERVER JOBS RUN AS ONE

In this article ❧ Automated systems rarely run alone. Operations teams schedule recurring jobs on shared hardware, and those jobs collide whenever their cycles align, forcing planners to reserve capacity for the moment of overlap. This problem shows how one arithmetic idea predicts that overlap, and how Python turns the same logic into a reusable tool.

The Problem

A cloud monitoring team runs two automated jobs on one server. A backup job runs every 15 minutes. A log cleanup job runs every 12 minutes. Both jobs ran together at 6 a.m.

When will they next run together?

  • a) 3 p.m.
  • b) noon
  • c) 6 p.m.
  • d) 7 a.m.
Click to Reveal the Answer

Correct Answer: d) 7 a.m. ✅

Math Solution

The two jobs repeat on fixed cycles that began together. The next shared run is the smallest span both cycles divide into evenly, the least common multiple. Factor each cycle, take the highest power of every prime, and multiply.

The overlap window is 60 minutes, so the jobs meet once every hour on the hour.

Step-by-Step Breakdown

The following sequence shows how the final time is derived:

  1. Factor each cycle: 15 = 3 × 5 and 12 = 2² × 3
  2. Take highest prime powers: 2² × 3 × 5
  3. Multiply: 60 minutes
  4. Add to the start: 6 a.m. plus 60 minutes → 7 a.m.

Historical Background

The idea of a shared multiple runs through nineteenth century number theory, when mathematicians formalized divisibility and the structure of the integers. In the twentieth century the same idea moved into engineering. Real time computing researchers found that a set of periodic tasks repeats its full pattern over a span equal to the least common multiple of the task periods, a span they named the hyperperiod. By the twenty first century that concept sits inside cloud schedulers and monitoring platforms, where it governs how recurring jobs share a processor without missing deadlines.

Python Version

The script finds the overlap for any two cycles, so it works for buses, alarms, or server jobs.

import math

def minutes_until_together(cycle_one, cycle_two):
    return math.lcm(cycle_one, cycle_two)

print("Let's find when two repeating jobs run together again.")
cycle_one = int(input("First job runs every how many minutes? "))
cycle_two = int(input("Second job runs every how many minutes? "))
result = minutes_until_together(cycle_one, cycle_two)
print("Both jobs run together again in this many minutes:", result)

Run it, enter the two cycle lengths, and it returns the minutes until the next shared run.
