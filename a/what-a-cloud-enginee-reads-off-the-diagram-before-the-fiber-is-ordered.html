WHAT A CLOUD ENGINEER READS OFF THE DIAGRAM BEFORE THE FIBER IS ORDERED

In this article ❧ Infrastructure documents carry commitments, not just pictures. A diagram that states its scale lets any reviewer recover a real distance from a drawn one, and distance drives latency estimates, procurement volumes, and permit filings, while a diagram without a scale shows topology and nothing measurable. This problem shows how one ratio, built from two lengths expressed in the same unit, turns a drawing into a measuring instrument, and how a short Python script keeps that conversion reusable.

The Problem

A cloud network engineer is documenting a private fiber link between two availability zones. The measured length of the link is 56 km. On the site topology diagram she prepares for the design review, the same link is drawn 4 cm long.

What is the scale factor of the diagram?

  • a) 1/14,000,000
  • b) 1/1,400,000
  • c) 1/14,000
  • d) 1/14
Click to Reveal the Answer

Correct Answer: b) 1/1,400,000 ✅

Math Solution

The two lengths must sit in one unit before they form a ratio, so the field length is converted from kilometres to centimetres, and the drawn length is then divided by it. The resulting fraction reduces to 1/1,400,000.

One centimetre on the sheet stands for 14 km of fiber, which is the same ratio read the other way.

Step-by-Step Breakdown

The following sequence shows how the final amount is derived:

  1. Field length in centimetres: 56 × 100,000 = 5,600,000
  2. Ratio of drawn length to field length: 4 / 5,600,000
  3. Reduced fraction: 1 / 1,400,000
  4. Kilometres per drawn centimetre: 56 / 4 = 14
  5. Verification: 4 × 14 = 56 km
  6. Answer: b) 1/1,400,000

Step Justified Solution

The same result written so that every line names the property that licenses it. Mode is compute, since the question asks for a value.

Setup

The fiber link has one length measured in the field and one length drawn on the topology diagram. Let d be the drawn length, 4 cm. Let L be the field length, 56 km. Let k be the scale factor, defined as the drawn length divided by the field length with both expressed in the same unit. So k = d/L.

Notation

  • k is the scale factor of the diagram, the unknown, a positive rational number with no unit.
  • d is the drawn length of the link on the diagram, 4 cm.
  • L is the field length of the link, 56 km, restated as 5,600,000 cm in Step 1.
  • cm is the centimetre, and km is the kilometre.
  • 105 is 100,000, the number of centimetres in one kilometre.
  • x/y is x divided by y, written as a fraction.
  • ⇒ reads implies.

Solution

  1. Definition of the kilometre. Property, 1 km = 105 cm. Inference, L = 56 km = 56(105) cm = 5,600,000 cm.
  2. Substitution. Property, x = y ⇒ x may replace y. Inference, k = d/L = (4 cm)/(5,600,000 cm). From line 1.
  3. Cancellation law, on the unit. Property, for y ≠ 0, (yx)/y = x. Inference, (4 cm)/(5,600,000 cm) = 4/5,600,000, so k carries no unit. From line 2.
  4. Fundamental principle of fractions. Property, for y ≠ 0 and z ≠ 0, (yx)/(yz) = x/z. Inference, 4/5,600,000 = (4)(1)/(4)(1,400,000) = 1/1,400,000. From line 3.
  5. Transitivity of equality. Property, x = y and y = z ⇒ x = z. Inference, k = 1/1,400,000. From lines 2, 3, and 4.

Verification

d = kL ⇒ (1/1,400,000)(5,600,000) = 5,600,000/1,400,000 = 4. Both sides match, and 1,400,000 cm = 14 km, with 4(14) = 56.

Answer

k = 1/1,400,000. One centimetre on the sheet stands for 14 km of fiber, which matches option b.

Historical Background

Stating a drawing scale as a bare fraction became standard practice once national survey offices began issuing map series rather than single sheets. In the middle of the twentieth century the United States Geological Survey settled its main topographic series on one ratio, 1 to 24,000, and published roughly 55,000 sheets on that single rule. The choice was administrative before it was mathematical, since one fixed ratio across a whole series let engineers, foresters, and planners measure across sheets and convert distances without relearning the rule each time.

Enterprise infrastructure documents inherited the same discipline. A campus layout, a rack elevation, and an availability zone topology all carry a stated scale so that the drawing can be measured rather than merely read.

Python Version

The script asks for the drawn length and the field length, then returns the scale of the diagram along with the kilometres each drawn centimetre represents, so it serves any drawing rather than this one case.

# What this does: works out the scale of a network diagram.
# Where it came from: an engineer drew a fiber link on a diagram and needed its scale.
# The math idea: compare the drawn length to the real length, both in the same unit.
# You type in: how long the link is on the diagram in centimetres, and how long it really is in kilometres.
# It prints: the scale of the diagram, and how many kilometres one centimetre stands for.

# This function does the math.
def diagram_scale(drawn_cm, field_km):
    # Change kilometres into centimetres. One kilometre is 100,000 centimetres.
    field_cm = field_km * 100000
    # Find how many real centimetres fit into one drawn centimetre.
    denominator = field_cm / drawn_cm
    # Find how many kilometres one drawn centimetre stands for.
    km_per_cm = field_km / drawn_cm
    # Send both answers back.
    return denominator, km_per_cm

# Tell the reader what we will figure out.
print("Let's find the scale of the network diagram.")

# Ask how long the link is on the diagram.
drawn_cm = float(input("Drawn length on the diagram in cm: "))

# Ask how long the link really is.
field_km = float(input("Field length of the link in km: "))

# Do the math.
denominator, km_per_cm = diagram_scale(drawn_cm, field_km)

# Show whole numbers without a trailing decimal.
denominator = int(denominator) if float(denominator).is_integer() else round(denominator, 2)
km_per_cm = int(km_per_cm) if float(km_per_cm).is_integer() else round(km_per_cm, 2)

# Print the answer with words that fit the scenario.
print("Diagram scale factor: 1 /", denominator)
print("One centimetre on the sheet stands for", km_per_cm, "km of fiber.")

Run it in a terminal, enter 4 for the drawn length and 56 for the field length, and it returns a scale of 1 in 1,400,000 with 14 km per centimetre.
